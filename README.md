# Бот учёта расходов

Telegram-бот для личного бюджета: записывает зарплату и аванс, расходы по категориям и регулярные платежи. Раз в неделю присылает анализ расходов, заранее напоминает о плановых платежах и показывает, сколько денег свободно до следующего поступления.

## Что умеет

- **Расходы** одним сообщением: `500 продукты`, `1 200 такси до работы`, `350 кафе вчера`, `300 кафе 25.10`. Если написать только сумму, бот предложит категорию кнопками.
- **Доходы**: `+60000 зарплата` или `/income 30000 аванс`.
- **Регулярные платежи**: `/regular 15 1200 связь Мобильный` (каждое 15-е число). За `REMIND_DAYS_BEFORE` дней и в день платежа приходит напоминание с кнопкой «Оплачено», которая записывает платёж в расходы. Неоплаченный платёж напоминается ежедневно.
- **Еженедельный отчёт** (по умолчанию в понедельник в 10:00): итог прошлой недели, категории с долями, крупнейшие траты, сравнение с прошлой неделей и средним за 4 недели, категории с заметным ростом, остаток с последнего поступления, сумма плановых платежей до следующей зарплаты и сколько можно тратить в день.
- `/balance`, `/week`, `/month`, `/lastmonth`, `/regulars`, `/categories`, `/export` (CSV для Excel), `/undo`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ALLOWED_USERS`.

### На сервере через Docker

```bash
git clone <репозиторий> expense-bot && cd expense-bot
cp .env.example .env && nano .env
docker compose up -d --build
docker compose logs -f
```

База хранится в `./data/expenses.db` на сервере; для резервной копии достаточно скопировать этот файл.

### Локально без Docker

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export $(grep -v '^#' .env | xargs)
python -m expense_bot
```

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота |
| `ALLOWED_USERS` | пусто (все) | Telegram ID через запятую |
| `TZ_NAME` | `Europe/Moscow` | Часовой пояс |
| `PAYDAYS` | пусто | Дни выплат, например `5,20`; без них бот определяет даты по истории |
| `REPORT_DAY`, `REPORT_HOUR` | `mon`, `10` | Когда присылать недельный отчёт |
| `REMINDER_HOUR` | `10` | Во сколько проверять плановые платежи |
| `REMIND_DAYS_BEFORE` | `2` | За сколько дней предупреждать |
| `DB_PATH` | `data/expenses.db` | Путь к базе SQLite |

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Структура: `expense_bot/parsing.py` — разбор ввода, `db.py` — SQLite, `reports.py` — анализ и тексты отчётов, `scheduler.py` — расписание, `bot.py` — обработчики Telegram.
