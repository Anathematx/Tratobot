# Запуск бота на сервере: пошагово для новичка

Займёт около 20 минут. Понадобятся: компьютер, телефон с Telegram и банковская карта. Программировать не нужно, только нажимать кнопки и копировать команды.

## Шаг 1. Создать бота в Telegram (3 минуты)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя (например, «Мои расходы») и адрес, который заканчивается на `bot` (например, `vladimir_trato_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH...`. Сохраните его, это пароль от бота, никому его не показывайте.
4. Откройте [@userinfobot](https://t.me/userinfobot), нажмите «Start» и запишите свой **Id** (число). По нему бот будет отвечать только вам.

## Шаг 2. Арендовать сервер (5 минут)

Сервер (VPS) — это маленький компьютер в дата-центре, который работает круглосуточно. Боту хватит самого дешёвого: 1 процессор, 1 ГБ памяти, 10–15 ГБ диска. Это стоит примерно 150–300 ₽ в месяц у любого российского хостинга (например, Timeweb Cloud, Selectel, REG.RU), оплата российской картой.

При создании сервера выберите:
- **Операционная система:** Ubuntu 24.04 (или 22.04).
- **Тариф:** самый дешёвый.
- **Доступ:** по паролю (ключи SSH можно не настраивать).

После создания в панели хостинга появятся **IP-адрес** сервера (вида `185.12.34.56`) и **пароль root**. Иногда пароль приходит на почту.

## Шаг 3. Дать серверу доступ к коду (3 минуты)

Репозиторий Tratobot приватный, поэтому серверу нужен ключ только для чтения.

1. Откройте [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new).
2. **Token name:** `tratobot-server`. **Expiration:** можно выбрать «No expiration» или год.
3. **Repository access:** «Only select repositories» → выберите `Tratobot`.
4. **Permissions** → **Repository permissions** → **Contents:** «Read-only».
5. Нажмите **Generate token** и скопируйте ключ вида `github_pat_...`.

> Если репозиторий сделать публичным (в коде нет паролей, токен бота хранится только на сервере), этот шаг можно пропустить и в шаге 4 убрать `Anathematx:КЛЮЧ@` из адреса.

## Шаг 4. Подключиться к серверу и запустить бота (5 минут)

**Подключение.** Проще всего через веб-консоль в панели хостинга (кнопка «Консоль» у сервера). Или с компьютера:
- **Windows:** нажмите Пуск, наберите `PowerShell`, откройте и введите `ssh root@IP-АДРЕС`.
- **Mac:** откройте программу «Терминал» и введите `ssh root@IP-АДРЕС`.

На вопрос `Are you sure you want to continue connecting` напишите `yes`. Затем вставьте пароль root (при вводе он не отображается, это нормально) и нажмите Enter.

**Установка.** Скопируйте команду ниже, замените `КЛЮЧ` на ключ из шага 3, вставьте в консоль (в PowerShell — правой кнопкой мыши) и нажмите Enter:

```bash
apt-get update && apt-get install -y git && git clone https://Anathematx:КЛЮЧ@github.com/Anathematx/Tratobot.git /opt/tratobot && bash /opt/tratobot/deploy/install.sh
```

Скрипт установит всё нужное и задаст три вопроса: токен бота, ваш Telegram ID и дни зарплаты. Когда появится надпись «Готово!», напишите своему боту `/start` в Telegram.

## Что дальше

- **Бот работает сам**, в том числе после перезагрузки сервера. Консоль можно закрыть.
- **Резервная копия базы** делается каждую ночь в `/opt/tratobot/backups`, хранятся последние 30 дней.
- **Обновить бота** до новой версии: подключитесь к серверу и выполните `bash /opt/tratobot/deploy/update.sh`.
- **Посмотреть логи**, если что-то не так: `cd /opt/tratobot && docker compose logs --tail 50`.
- **Поменять настройки** (время отчёта, дни зарплаты): `nano /opt/tratobot/.env`, сохранить (Ctrl+O, Enter, Ctrl+X), затем `cd /opt/tratobot && docker compose up -d`.
